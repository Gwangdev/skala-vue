# 2. Weather Mockup

> `v-for` / `v-if` / `:value`+`@input` / 이벤트 수식어 종합 실습

## 과제 요구사항

1. **배열 렌더링 (`v-for`)**: 날씨 데이터 배열을 카드로 반복 출력, `:key`는 `id`
2. **조건부 렌더링 (`v-if`)**: 25도 기준 "🔥 더움" / "❄️ 선선함" 라벨 부여
3. **양방향 바인딩 및 한글 처리 (`:value` + `@input`)**: `v-model` 대신 사용 -> IME 조합 중에도 값이 즉시 반영되도록 함
4. **이벤트 + 수식어**: 카드 클릭 시 "{도시}이 선택되었습니다." 표기, 상세보기 버튼은 `@click.stop`으로 버블링 차단 후 `window.alert`
5. 본인 데이터/기능 추가

파일: `src/components/exercise/WeatherMockup.vue`

## 과제 세부 개발내용

- **데이터 확장**: 도시 3개 → 6개(연고지 포함), `humidity`/`icon` 필드 추가
- **조건부 스타일**: 25도 기준 카드 배경색 분기 (`:class`)
- **즐겨찾기**: ⭐ 토글 + "즐겨찾기만 보기" 필터. 상태는 배열(`ref([])`) + `includes`/`filter`
- **필터 렌더링**: `v-for`는 전체 순회, 카드에 `v-show`로 노출 제어 — 즐겨찾기 필터는 빈번한 토글이라 `v-if`보다 비용이 낮은 `v-show`가 적합
- **빈 검색어 안내**: `v-if="!searchQuery"`로 "전체 N개 도시" 표시
- **이벤트 확장**: 호버 확대·배경색 변화(`@mouseenter`/`@mouseleave`), 검색 확정(`@submit.prevent`), 검색 초기화(`@keyup.esc`)
- **디렉티브 반영**: `v-show`(툴팁·필터) / `v-once`(안내문) / `v-pre`(문법 예시) / `v-cloak`(루트) / `v-text`(검색어 표시) / `v-html`(신뢰 가능한 정적 문자열)

## `v-if` 대신 `v-show`를 쓴 기준

| 비교 항목   | v-if                       | v-show                            |
| ----------- | -------------------------- | --------------------------------- |
| 렌더링 방식 | DOM 파괴/생성              | CSS `display` 조작                |
| 전환 비용   | 높음                       | 낮음                              |
| 실무 권장   | 드문 전환 (로그인 화면 등) | 빈번한 전환 (모달·탭·아코디언 등) |

즐겨찾기 필터는 후자에 해당하므로 v-show 처리
